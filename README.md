# Skills-CapeStream

Skills de Claude Code hechas para Cape Stream y proyectos relacionados.

## skills/ (proyectos y herramientas)

| Skill | Qué hace | Origen |
|---|---|---|
| cloudflare-eficiencia-seguridad | Límites del plan gratis y reglas de /pub y /api/admin | Just Do It |
| nfc-card | Tarjetas personales NFC (cape.stream/perfil) | Just Do It |
| turnstile-spin | Cloudflare Turnstile de punta a punta (variante del proyecto) | Just Do It |
| uxui-frontend | Criterio de UX/UI y frontend | Just Do It |
| crm-panel-gestion | CRM / panel de gestión multi-tenant | Manager |
| cartelera-tv-tizen | Cartelería digital para Smart TV Samsung Tizen | carteleria-tv |
| estudio-video | Videos y animaciones de punta a punta | ~/.claude/skills |

## skills-libros/

Pipeline de libros (Book Genesis v4): copia de `book-genesis-v4/skills`, con sus carpetas `optional/` y `deprecated/`.

## Uso

Copiar la carpeta de la skill a `.claude/skills/` del proyecto (o a `~/.claude/skills/` para usarla en todos).
